# DNN 训练 GPU 显存优化综述

> 该综述系统梳理了近十年来 DNN 训练框架在 GPU 显存高效利用与优化方面的代表性研究，并整理提供相关论文资源，方便读者查阅、下载与学习。

## 项目简介

GPU 显存已成为现代深度神经网络（DNN）训练中的关键资源瓶颈。模型参数、优化器状态、梯度、激活值、通信缓冲区以及临时张量需要共同占用有限的 GPU 显存。当模型规模或训练状态超出显存容量时，训练框架通常需要采用重计算、卸载、压缩、内存复用等显存优化技术。然而，不同技术在显存节省、计算开销、数据传输和训练性能等方面存在不同的权衡，也适用于不同的模型、硬件和训练场景。

本仓库是 **DNN 训练 GPU 显存优化综述** 的配套资料库，主要提供三部分内容：

1. 从“**技术分类—核心挑战—解决方案类别—代表工作**”逐层展开的分类体系；
2. 与综述内容对应的代表性论文及相关资料；
3. 从显存节省、计算开销、通信开销、精度影响和系统复杂度等方面，比较不同显存优化技术的优势、局限及适用场景。

## 五类显存优化技术

### 1. 数据卸载技术（§4）

数据卸载通过在 GPU、CPU 内存和 NVMe SSD 等存储层级之间迁移张量来扩展可用显存，其核心问题是数据传输可能阻塞计算、降低训练吞吐率。综述从四个方向讨论降低卸载开销的方法：

- **迁移延迟隐藏（§4.1.1）**：通过计算与传输重叠、提前预取等方式隐藏迁移延迟。
- **CPU-GPU 混合执行（§4.1.2）**：让 CPU 与 GPU 共同参与训练计算。
- **联合内存优化（§4.1.3）**：将换入换出与重计算、压缩、分配或调度结合。
- **数据路径优化（§4.1.4）**：优化 GPU、主存与存储设备之间的数据层级和传输路径。

该类别现收录 [19 份论文文件](papers/Data-Offloading/)。

### 2. 激活重计算优化（§5）

激活重计算在前向传播时丢弃部分中间结果，并在反向传播需要时重新计算，以额外计算换取显存空间。综述关注两个核心问题：如何控制重计算开销，以及如何高效搜索重计算策略。

- **自适应重计算（§5.1.1）**：根据显存压力、执行状态或流水线行为动态调整策略。
- **重计算开销隐藏（§5.1.2）**：利用流水线空闲时间或并行执行隐藏额外计算。
- **基于启发式的方法（§5.2.1）**：使用实用启发式规则搜索低成本检查点策略。
- **基于 ILP 的全局方法（§5.2.2）**：将重计算建模为全局优化问题。

该类别现收录 [20 份论文文件](papers/Activation-Recomputation/)。

### 3. 数据压缩技术（§6）

数据压缩使用低精度、量化、稀疏化或低秩表示减少激活、梯度、优化器状态或模型数据的占用。有效的压缩方法需要在节省显存的同时控制编码解码成本，并保持模型收敛性和精度。

- **保障模型精度的压缩方法（§6.1）**
  - *自适应低精度压缩（§6.1.1）*：为不同数据选择合适的数值格式和精度。
  - *误差可控的低秩压缩（§6.1.2）*：在控制近似误差的同时降低数据秩。
  - *选择性压缩（§6.2.1）*：只压缩能够获得良好显存收益的张量。
  - *高效压缩算法（§6.2.2）*：降低元数据、格式转换和运行时开销。

该类别现收录 [31 份论文文件](papers/Data-Compression/)。

### 4. 分布式 GPU 显存优化（§7）

分布式训练通过将模型状态分片到多个设备，为突破单卡显存容量限制提供了重要手段，但同时也带来了新的显存管理挑战。

- **消除数据冗余（§7.1）**：细粒度切分参数、梯度和优化器状态。
- **长生命周期激活显存最小化（§7.2）**：通过调度和集成式显存优化缩短激活生命周期。
- **跨设备显存负载均衡（§7.3）**：通过负载重分配、结合其他显存优化、算法设计或显存感知并行编排改善设备间不均衡。

该类别现收录 [35 份论文文件](papers/Distributed-Memory-Optimization/)。

### 5. 其他优化（§8）

部分显存瓶颈并非只由模型状态或激活值引起。显存碎片会造成空闲空间无法使用，算子工作区和中间张量则可能产生很高的瞬时显存峰值。

- **GPU 显存碎片整理（§8.1）**
  - *静态分区（§8.1.1）*：    预先划分显存空间，为不同类型的张量或任务分配相对固定的内存区域，减少不同内存需求之间的相互干扰。
  - *预规划分配（§8.1.2）*：    预先规划张量的放置与复用，利用已知的张量大小和生命周期，在训练执行前确定内存地址及复用关系，以降低峰值显存占用。
  - *运行时碎片管理（§8.1.3）*：    动态处理执行过程中产生的显存碎片，针对运行时难以提前预测的分配与释放，通过合并、迁移或重新组织空闲空间提高显存利用率。
- **临时缓冲区缩减（§8.2）**
  - *算子优化（§8.2.1）*：重新设计高显存占用算子。
  - *计算图优化（§8.2.2）*：调整算子顺序、图执行方式或内存布局。

该类别现收录 [21 份论文文件](papers/Other-Optimizations/)。
